##Project Overview##
The Bus Ticket Booking Platform is a Java-based application integrated with a MySQL database that enables users to book bus tickets seamlessly.
The system allows passengers to enter their details, which are securely stored and managed in a relational database. Core backend logic handles ticket booking, passenger management, and database operations to simulate a real-world booking flow. 
The project uses JDBC connectivity via the MySQL Connector JAR file to establish communication between Java and MySQL, ensuring reliable data transactions. This platform demonstrates practical implementation of database integration, CRUD operations, and backend workflow design, making it a strong foundation for learning enterprise-level application development.
